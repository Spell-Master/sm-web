Colunas Automáticas

col-auto ⇒ É uma coluna coringa pois tem seu comportamento distinto.

Diferente das demais colunas ela não possui nenhuma marcação de quantas podem exisitr em uma única linha, as colunas defindas como tal se divididem entre os elementos na linha.

Uma coluna altomática quando não pode mais oculpar seu espaço na linha, ela salta para baixo se empilhando.

Colunas dessa propriedade requerem observações:

  • Não possuem uma largura determinada.
  • Podem se expandir levianamente.
  • Podem saltar a linha de forma inesperada.
  • A propriedade fix não funciona.
  • A propriedade reverse não funciona.

Coluna Fixa

fix ⇒ Pode ser aplicada a linha quanto a uma coluna específica.

Mas quando definido a uma coluna interage apenas com ela.

Essa coluna é impedida de se expandir conforme a disponibilidade de tela.

Reversão Adaptativa

Atenção:

Esta é uma propriedade de uso limitado, ela pode causar vazamento de bloco com muita facilidade.

reverse ⇒ Pode ser aplicada a linha quanto a uma coluna específica.

Mas quando definido a uma coluna interage apenas com ela.

Altera o comportamento da coluna ao inverso do normal.

Ou seja a coluna permacem expandida e empilhada na linha, no entanto quando a largura de tela combinar com suas definições de escala se retrae ao tamanho de prefixo.
