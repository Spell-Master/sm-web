ImageGalery

Exibe imagens como galeria.

Utiliza recuro da API Image

Apresentação

Ao verificar veja a resposta no console do navegador.

Utilização

Adicione os arquivos necessários

<link href="ImageGalery.css" rel="stylesheet" type="text/css"/>
<script src="ImageGalery.js" type="text/javascript"></script>

Declare a instância ao final do documento:

<script>galeria = new ImageGalery();</script>

Opções de Iniciação

  • zIndex ⇒ (opcional) Informar um valor inteiro para definir para definir o valor da propriedade de estilo "z-index" para a galeria, caso não informado a galeria vai possuir o seguinte valor... z-index:1
  • images ⇒ (opcional) Informar uma ou mais imagens presentes no documento para serem anexadas a galeria.

NOTA:

Imagens podem ser adicionadas ou removidas posteriormente depois na iniciação da ImageGalery

Exemplo de iniciação com as opções:

<img src="exemplo-a" alt="" height="200" width="200" />
<img src="exemplo-b" alt="" height="200" width="200" />
<img src="exemplo-c" alt="" height="200" width="200" />
<script>
    var exemplo = document.querySelectorAll('img');
    var galeria = new ImageGalery({
        zIndex: 999,
        images: exemplo
    });
</script>

Funções Extras

add

Adiciona imagens a galeria.

<img src="imagem-a.png" alt="" height="200" width="200" id="exemplo-id" />
<img src="imagem-b.png" alt="" height="200" width="200" class="exemplo-class" />
<img src="imagem-c.png" alt="" height="200" width="200" class="exemplo-class" />
<script>
    var galeria = new ImageGalery();
                            
    var adionarMultiplas = document.getElementsByClassName('exemplo-class');
    var adionarUnica = document.getElementById('exemplo-id');
                            
    galeria.add(adionarMultiplas);
    galeria.add(adionarUnica);
</script>

remove

Remove imagens a galeria.

<img src="imagem-a.png" alt="" height="200" width="200" />
<img src="imagem-b.png" alt="" height="200" width="200" />
<img src="imagem-c.png" alt="" height="200" width="200" />
<script>
    var exemplo = document.querySelectorAll('img');
    var galeria = new ImageGalery({images: exemplo});
                
    galeria.remove(exemplo[1]); // Remove a segunda imagem
</script>

check

Informa um array com todas imagens anexas a galeria.

<img src="imagem-a.png" alt="" height="200" width="200" />
<img src="imagem-b.png" alt="" height="200" width="200" />
<img src="imagem-c.png" alt="" height="200" width="200" />
<script>
    var exemplo = document.querySelectorAll('img');
    var galeria = new ImageGalery({images: exemplo});
                
    galeria.check();
</script>

Dica de uso

Antes de inicar a ImageGalery já com imagens ou anexa-las posteriormente, faça uma verificação se cada imagem já está completamente carregada.

Assim pode-se evitar transtornos com falhas já que a imagem é anexa antes mesmo que ela esteja pronto para uso.

var contar = 0;
var imagens = document.querySelectorAll('img');
for (var i = 0; i < imagens.length; i++) {
    imagens[i].addEventListener('load', contarCarregadas, false);
}

function contarCarregadas(e) {
    contar++;
    if (contar === imagens.length) { // A quantidade carregada é igual a quantidade requisitada
        // Pode-se inicar a ImageGalery sem problemas
    }
}
