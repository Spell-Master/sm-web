ImageCut

Realiza corte em imagem.

Utiliza recuro da API Image

Apresentação

Utilização

Adicione os arquivos necessários.

<script src="ImageCut.js" type="text/javascript"></script>
<link href="ImageCut.css" rel="stylesheet" type="text/css" />

Adicione alguma tag IMG

<img src="imagem.jpg" id="alvo-do-corte" alt="" />

ATENÇÃO

Tenha certeza que a imagem renderizada possua 250 pixe's ou mais de altura e largura.

Com a imagem identifica inicie o script 
<img src="imagem.jpg" id="alvo-do-corte" alt="exemplo" />
<script>
    var cortar = new ImageCut( document.getElementById('alvo-do-corte') );
</script>

Funções Extras

setCut

Realiza o corte da área selecionada.

Deve ser acionada por ação externa como por exemplo um botão alocando na memória em base-64 os dados do corte.

<img src="imagem.jpg" id="alvo-do-corte" alt="exemplo" />
<button id="cortar">Cortar Imagem</button>
<script>
    var cortar = new ImageCut( document.getElementById('alvo-do-corte') );
    document.getElementById('cortar').click(function (e) {
        cortar.setCut();
    }, false);
</script>

getImage

Obtem os dados da area cortada.

Pode ser acionada por ação externa logo após a função setCut for executada.

<img src="imagem.jpg" id="alvo-do-corte" alt="exemplo" />
<button id="cortar">Cortar Imagem</button>
<script>
    var cortar = new ImageCut( document.getElementById('alvo-do-corte') );
    var dados = '';
    document.getElementById('cortar').click(function (e) {
        cortar.setCut();
        dados = cortar.getImage();
    }, false);
</script>

sizePlus

Almenta em 10 pixel's o tamanho da área de corte.

Pode ser acionada diversas vezes ampliando cada mais a área.

<img src="imagem.jpg" id="alvo-do-corte" alt="exemplo" />
<button id="ampliar">Ampliar</button>
<script>
    var cortar = new ImageCut( document.getElementById('alvo-do-corte') );
    document.getElementById('ampliar').click(function (e) {
        cortar.sizePlus();
    }, false);
</script>

sizeMinus

Almenta em 10 pixel's o tamanho da área de corte.

Pode ser acionada diversas vezes reduzindo cada mais a área.

<img src="imagem.jpg" id="alvo-do-corte" alt="exemplo" />
<button id="reduzir">Reduzir</button>
<script>
    var cortar = new ImageCut( document.getElementById('alvo-do-corte') );
    document.getElementById('reduzir').click(function (e) {
        cortar.sizeMinus();
    }, false);
</script>

Lembre-se que o corte não passa de uma representação em base64 da imagem no local onde está a caixa de corte, portanto esse valor pode ser utilizado por uma infinidade de situações, conforme for necessário um corte de imagem.

ImageCut não se iniciará enquanto a imagem não estiver completamente carregada, portanto para images grandes dependendo da velocidade de conexão e capacidade de processamento da máquina do usuário, o script pode demorar a está operacional.
