Largura e Altura

Propriedades de tamanho horizontal e vertical combinadas

— Largura e Altura —

Propriedades de largura podem ser combinas com altura idêntica, apenas adicionando a propriedade height em conjunto.

O mesmo resultado é obtido com propriedades de altura junto com a propriedade width.

Exemplo:

width-200 ⇒ Adiciona a largura.

height ⇒ Adiciona a altura igual a largura.

<div class="width-200 height"></div>

height-200 ⇒ Adiciona a altura.

width ⇒ Adiciona a largura igual a altura.

<div class="height-200 width"></div>

— Complemento —

Qualquer propriedade de largura pode ser combinada com a propriedade height.

Qualquer propriedade de altura pode ser combinada com a propriedade width.

Ambas expecificações são para unir as propriedades de medidas para uma só composição.
