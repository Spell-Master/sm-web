ModalShow

Interface Modal.

Apresentação

Escolha um efeito de transição

Utilização

Adicione os arquivos necessários:

<link href="ModalShow.css" rel="stylesheet" type="text/css"/>
<script src="ModalShow.js" type="text/javascript"></script>

Crie a estrutura HTML:

<div class="modal" id="exemplo">
    <div class="modal-show-box">
        <div class="modal-show-header"></div>
        <div class="modal-show-content">
            O conteúdo do modal aqui dentro...
        </div>
    </div>
</div>

IMPORTANTE

É necessário usar exatamente essa aquitetura, apenas pode-se usar atributos ID, DATASET's ou qualquer outra condicional que o identifique.

Declare a instância no final do documento, informando qual elemento será usado:

<script>
    var exemplo = document.getElementById('exemplo'); // elemento modal alvo
    var modal = new ModalShow(exemplo);
</script>

Funções

open

Abre o modal.

var exemplo = document.getElementById('exemplo');
var modal = new ModalShow(exemplo);
modal.open();

close

Fecha o modal somente quando ele já foi aberto.

var exemplo = document.getElementById('exemplo');
var modal = new ModalShow(exemplo);
modal.open();
modal.close();

showX

Adiciona o botão X de fechar caso ele não esteja ativo.

var exemplo = document.getElementById('exemplo');
var modal = new ModalShow(exemplo);
modal.open();
modal.showX();

hiddenX

Remove o botão X de fechar caso ele esteja ativo.

var exemplo = document.getElementById('exemplo');
var modal = new ModalShow(exemplo);
modal.open();
modal.hiddenX();

title

Define/altera o texto título do modal.

var exemplo = document.getElementById('exemplo');
var modal = new ModalShow(exemplo);
modal.open();
modal.title('Texto título do modal');

content

Define/altera o conteúdo do modal.

var exemplo = document.getElementById('exemplo');
var modal = new ModalShow(exemplo);
modal.open();
modal.content('<p>Um paragrago</p> <p>Outro paragrago</p>');

Opções métodos/callback's

  • zIndex ⇒ (opcional) Informar um valor numério de importância para o atributo z-index do modal.

    Caso não definido esse valor será 1.

  • width ⇒ (opcional) Informar um valor numério de largura máxima em pixel's do modal.

    Caso não informado a largura será em 90% da tela em pixel's.

  • title ⇒ (opcional) Informar um valor em texto para ser usado no título do modal.

    Caso não informado o modal abre sem título.

  • effect ⇒ (opcional) Informar um valor em texto para ser usado como efeito de transição do modal.

    Caso não informado nenhum efeito será usado.

    Confira abaixo a lita de efeitos disponíveis.

  • close ⇒ (opcional) Informar um valor true ou false para adicionar ou não o botão de fechar.

    Caso não informado essa opção será considerada como true.

  • onOpen ⇒ (opcional) Informar uma função que será executada toda vez que o modal for aberto.
  • onClose ⇒ (opcional) Informar uma função que será executada toda vez que o modal for fechado.

Lista de efeitos de transição

  • fade
  • zoom
  • top
  • bottom
  • left
  • right

Exemplo Prático

<div class="modal" id="exemplo">
    <div class="modal-box">
        <div class="modal-header">
        </div>
        <div class="modal-content"></div>
    </div>
</div>

<button>Abrir modal exemplo</button>

<script>
    var exemplo = document.getElementById('exemplo'); // elemento de modal alvo
    var modal = new ModalShow(exemplo); // Intancia do ModalShow informando o alvo

    // Botão de ativação
    document.querySelector('button').addEventListener('click', function (e) {
        modal.open({
            zIndex: 9, // valor z-index
            width: 900, // Largura máxima
            title: 'Texto do titulo', // Texto do título
            effect: 'fade', // Efeito de transição
            close: false, // Não adicionar o botão de fechar
            onOpen: function () { // Fazer alguma coisa quando abrir
                console.log('Foi aberto o modal');
            },
            onClose: function () { // Fazer alguma coisa quando fechar
                console.log('Foi fechado o modal');
            }
        });
    }, false);
</script>
