Tabela

Propriedades para tabelas

ATENÇÃO!

A propriedade table aqui apresentada, só é funcional em elementos de tabela (<table>).

Em qualquer outro elemento quando aplicada, seu resultado é de exibição e não estrutura de arquitetura visual da tabela como nos usos deste documento.

— Vazamento —

Tag's table junto a propriedade também chamada table tenta se adaptar a largura do elemento.

No entanto a tabela é um elemento problemático quanto a responsabilidade na compatibilidade com telas de visualização menor.

Se não for mais possível retrair a largura um vazamento vai acontecer.

Como sugestão aconselho quando necessário usar propriedades de vazamento em algum elemento, então a tabela é adicionada internamente.
