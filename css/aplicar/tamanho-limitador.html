Tamanho Limitado

Propriedades de tamanhos de limitação

NOTA!

Neste documento será apenas algumas propriedades na prática, ao final teremos uma lista com todas propriedades para categoria de tamanho iimitado.

— Largura Mínima —

Propriedades que extendem horizontalmente para uma largura mínima.

Quer dizer que o elemento pode possuir largura maior que o definido, mas nunca menor.

width-min-200

200 pixels de largura mínima

width-min-400

400 pixels de largura mínima

width-min-600

600 pixels de largura mínima

— Largura Máxima —

Propriedades que extendem horizontalmente para uma largura máxima.

Quer dizer que o elemento pode possuir largura menor que o definido, mas nunca maior.

width-max-200

200 pixels de largura máxima

width-max-400

400 pixels de largura máxima

width-max-600

600 pixels de largura máxima

— Altura Mínima —

Propriedades que extendem verticalmente para uma altura mínima.

Quer dizer que o elemento pode possuir altura maior que o definido, mas nunca menor.

height-min-100

100 pixels de altura mínima

height-min-150

150 pixels de altura mínima

height-min-200

200 pixels de altura mínima

— Altura Máxima —

Propriedades que extendem verticalmente para uma altura máxima.
