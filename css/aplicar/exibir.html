— Visual de Bloco —

Elemento de bloco visível

Veja o bloco escondido no inspetor.

Elemento de bloco escondido, somente visível pelo código fonte

— Inconsistência —

Declarações incoerentes devem ser evitadas, digamos as seguintes definições:

<div class="none block">Erro ou falta de atenção</div>
<div class="block none">Erro ou falta de atenção</div>

Perceba que no primeiro divisor declarei none depois block e no segundo divisor declarei ao inverso.

Sendo assim, duas propriedades de resultados inversos, para contexto que determinha como o elemento vai ser renderizado.

Ou seja quero que seja bloco, mas oculto; o que não faz nenhum sentido, um elemento não pode ser bloco ou oculto ao mesmo tempo.

Em ambos os casos os elementos serão tratados como caixa de bloco visíveis.

Declarando as duas propriedades no mesmo elemento: none block, o elemento sempre será uma caixa de bloco.

none block Declaração de propriedades sem coerência.

— Anulando Propriedades —

Muitas ás vezes para uma integração com o usuário, por alguma razão geralmente por script um elemento que estar oculto deve ser mostrado, ou virse-e-versa.

Podemos usar:

  • show para anular none
  • hide para anular block

Declarando: hide anula o efeito de block.

Elemento oculto pela propriedadade "hide"

Declarando: show anula o efeito de none.

Elemento visível pela propriedadade "show"

— Hierarquia na Definição —

Quando as propriedades show e hide estão definidas no mesmo elemento, a ordem ao qual é declarado vai interferir como esse elemento vai ser exibido.

Definido primeiro hide depois show, nesse contexto segunda propriedade anula a primeira propriedade declarada.

— Renderização de Bloco como Tabela —

  • table ⇒ Faz com que o elemento se comporte como uma tag <table>, mas como uma caixa de nível de bloco.
  • table-row ⇒ Faz com que o elemento se comporte como uma tag <tr> linha pertencente a tag <table>
  • table-cell ⇒ Faz com que o elemento se comporte como uma tag <td> coluna pertencente a tag <tr> em uma <table>

  • show-max ⇒ Visível se a resolução de tela for inferior a 960 pixel's.
  • show-md ⇒ Visível se a resolução de tela for inferior a 640 pixel's
  • show-min ⇒ Visível se a resolução de tela for inferior a 480 pixel's
