Utilização

Adicione os arquivos necessários

<link href="pLoading.css" rel="stylesheet" type="text/css"/>
<script src="pLoading.js" type="text/javascript"></script>

Antes de prosseguir com o uso temos de conhecer as opções pois elas vão determinar o uso geral, pois as funções compartilham os quase mesmos dados, só alterando mesmo qual é o tipo de animação a ser utilizada.

Opções

  • target ⇒ (opcional) deve-se informar um elemento no documento onde a animação deve acontecer Caso não informado o alvo será o corpo do documento.
  • size ⇒ (opcional) Informe um numero para corresponder a altura e largura da animação Caso não informado o tamanho será de 50 pixel's.
  • color ⇒ (opcional) Você informa um #hex code RGB para definir qual a cor da animação usada Caso não informado a cor será #000000.
  • bg ⇒ (opcional) Você informa um #hex code RGB para definir qual a cor de fundo na animação será usada para cobrir o alvo. Caso não informado o elemento alvo não sofre cobertura
  • img ⇒ (brigatório/para animação de imagem) Você informa o endereço de uma imagem para ser usada como animação.

Variações das opções

  • size ⇒ Esta opção não tem uso quando a animação usada for a barra de progresso.
  • bg ⇒ Esta opção sempre que usada vai cobrir o elemento alvo.
  • img ⇒ Esta opção somente é usada e obrigatória se usar a função de animação por imagem, para as demais funções não tem uso.

ATENÇÃO!

Tenha certeza que o elemento ao qual a animação será adicionada não possua propriedade inline style.

Quando usar a opção bg para cobrir o alvo da animação tenha certeza que esse elemento alvo não tenha propriedades de posição (position) no css.

Funções

Usando Imagens
pLoading.image.add({
    // elemento alvo da animação
    target: document.getElementById('#elemento_alvo'),
    // altura e largura em pixels para a imagem
    size: 100,
    // local e imagem que será usada
    img: 'endereco/diretorio/arquivo.gif'
});

// A mesma coisa, mas adicionando uma capa por cima do alvo
pLoading.image.add({
    // elemento alvo da animação
    target: document.getElementById('#elemento_alvo'),
    // altura e largura em pixels para a imagem
    size: 100,
    // local e imagem que será usada
    img: 'endereco/diretorio/arquivo.gif',
    // cor de fundo na animação que cobre o alvo
    bg: '#cccccc'
});

Através dessa função você adiciona imagens, mas tenha consiência que essa imagem terá que ser baixada pelo navegador utilizado pelo usuário.

Portanto imagens muito grande/pesadas poderão demorar muito até de fato aparecerem, o mesmo vale caso use um endereço http para buscar (nesse caso se torna mais lento ainda).

Prefira usar imagens bem simples e leves e jamais importe elas de outra url, somente use imagens que esteja dentro de algum diretório do seu website.

Usando Progresso Circular
pLoading.circle.add({
    // elemento alvo da animação
    target: document.getElementById('#elemento_alvo'),
    // altura e largura em pixels da animação
    size: 100,
    // cor da animação
    color: '#4285f4'
});
// A mesma coisa, mas adicionando uma capa por cima do alvo
pLoading.circle.add({
    // elemento alvo da animação
    target: document.getElementById('#elemento_alvo'),
    // altura e largura em pixels da animação
    size: 100,
    // cor da animação
    color: '#4285f4',
    // cor de fundo na animação que cobre o alvo
    bg: '#cccccc'
});
Usando Barra Percentual
pLoading.bar.add({
    // elemento alvo da barra de progresso
    target: document.getElementById('#elemento_alvo'),
    // cor da barra de progresso
    color: '#ff0000'
});
// A mesma coisa, mas adicionando uma capa por cima do alvo
pLoading.bar.add({
    // elemento alvo da barra de progresso
    target: document.getElementById('#elemento_alvo'),
    // cor da barra de progresso
    color: '#ff0000',
    // cor de fundo na animação que cobre o alvo
    bg: '#cccccc'
});
Atualizar Barra Percentual

Diferente das demais funções a barra de progresso apesar de adicionada terá que ser atualizada para definir sua largura.

O que pode ser feito com sua função de atualização informando o percentual dessa largura, sendo o valor mínimo 0 "zero" e o valor máximo 100 "cem", ou seja em quantos % porcento a barra deve ser alterada.

Essa função pode ser chamada quantas vezes for necessário.

pLoading.bar.update(0); // 0% de sua largura (estado inicial e menor valor possível)
pLoading.bar.update(10); // Barra de progresso com 10% de sua largura
pLoading.bar.update(35); // Barra de progresso com 35% de sua largura
pLoading.bar.update(90); // Barra de progresso com 90% de sua largura
pLoading.bar.update(100); // Barra de progresso com 100% de sua largura (maior valor possível)

Remover Animação

Todas animações uma vez adicionadas permanecerão no local até serem removidas.

Cada função de animação possui sua forma própria para remover.

pLoading.image.remove(); // Remove a animação criada por imagem
pLoading.circle.remove(); // Remove a animação circular
pLoading.bar.remove(); // Remove a animação da barra de progresso
