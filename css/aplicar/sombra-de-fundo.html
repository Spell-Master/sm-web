Sombra de Fundo

Propriedades para sombreamento de elementos

A intencidade de sombra é variável de navegador para navegador, pois não existe um padrão consenso.

A qualidade da sombra também será afetada pela capacidade no processamento gráfico do aparelho do usuário.

Mova seu ponteiro (cursor/mouse) sobre os elementos para visualizar.
